# Held-out set 1

- `en-next-friday-haircut`: plain haircut booking, "next friday" said on a Saturday, "ten thirty", number dictated in three groups.
- `en-fourth-colour-double`: colouring on "friday the fourth" (falls in the next month), "half past two", number with three "double"s.
- `en-tomorrow-beard-card-pauses`: British voice, beard trim "tomorrow" at "two pm", number read off a card with long pauses mid-number.
- `en-interrupt-change-time`: caller interrupts the read-back to move the time from half past three to half past four; number with "triple seven".
- `en-hours-question-backchannel`: question-only call about opening hours and services with "mhm"/"yeah" backchannels; nothing booked.
- `en-ask-for-person`: caller who left an umbrella asks to be put through to a person; transfer, nothing booked.
- `en-taken-saturday-slot`: Saturday 10:00 (and 10:30) taken; caller names eleven o'clock herself; must book 11:00.
- `en-car-speakerphone-thursday-late`: car speakerphone with loud late echo and pink noise; haircut Thursday 19:00 (late opening); number with "double four".
- `de-uebermorgen-halb-drei`: German haircut "übermorgen um halb drei" (14:30); caller pauses while dictating the number.
- `de-am-dienstag-faerben-paare`: German colouring "am dienstag um elf uhr"; number dictated in two-digit pairs; "mhm" backchannel during read-back.
- `de-morgen-bart-korrektur-nummer`: German beard trim "morgen um sechzehn uhr dreißig"; caller interrupts the read-back to correct the last digit of the number.
- `de-samstag-belegt-laerm`: German caller on a busy street (babble noise, some echo); Saturday 10:00 and 10:30 taken; caller picks "halb zwölf"; number with "zwo".

This set was written from `calls/WRITING_CALLS.md` only, without reading the runtime's code, settings, tests, docs or any other call files.
